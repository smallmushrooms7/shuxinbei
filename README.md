## 打得怎么样

- 个人赛实操 0 解。IOT CAN 那道赛后 11-14 号离线复现完整做出来了，flag `flag{c4n_1s_n0t_4_s4f3_bus_7e0_2026}`，链路是 candump → UDS 安全访问（27 03/27 04）→ 未 strip ELF 符号表还原密钥推导 → LCG 异或密钥流 → ISO-TP 重组 → 解密 DID。
- 团队赛写出来前 7 关加任务 13，第三层的数据库/缓存服务器没打进去，任务 8-12、14-18 断了。

## 几条最主要的教训

1. 附件是一张图 + 一个服务的组合，第一优先级永远是先连服务，而不是先抠图。
2. 赛后复盘比考场硬磕有产出：环境没了，附件还在的题都能继续做。
3. 源码泄露（www.zip）是全局钥匙，看到就立刻下载审计。
4. 密钥复用会把多个系统连成一条链，JWT 密钥共用是内网横向的常见跳板。
5. 过关制比赛忌讳一关死磕，跳过当前关先拿后面的权限，前面的关往往顺带就出来了。
